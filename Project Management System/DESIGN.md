# Requirements

Since the project is broken up into versions, the format will go like this:

- Build a feature dependant on version and focus purely on the adding the feature designated to that specific version.
- Build supporting features for that main feature to enhance the experience of the program.
- Reflect on the progress made.
- Duplicate the version folder and rename to a version up.
- [DEPENDANT]: potentially there may be a case in which sub-versions like; version 1.1 or version 1.12 may occur depending on the timeframe that the supporting feature was developed or delayed.
