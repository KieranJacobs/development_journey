# PROJECT MANAGEMENT SYSTEM

The aim for this project is to develop a helpful management system for student aiming to organize and sort their projects based on various factors such as;

- Priority
- Scale
- Topic
- Project-Type

To achieve this we will be making incremental versions to show the stages of the project's development timeline, and also to serve as a personal time-capsule of the project so I can have a visual representation of all its phases, as I progress and add more features or build depth within the project.

## FOR CLARIFICATION

I am using this project to endlessly develop my skills in Python and a multitude of languages by using the project as a basis to problem solve, debug, and understand/comprehend any errors or issues that I may encounter on my programming journey. To ensure that my goals of improving my fluency in this programming Language, I am devoting as much time as I can to this project to ensure that my mental projection of the future is relatively the same all the way through the development, UNTIL I have completed 1 main feature + its supporting elements, before I move onto a new version and that idea of what this project looks like in the future changes drastically.
