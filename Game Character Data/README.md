# Game Character Data Exercise START

This is an exercise that helps me practice working with JSON syntax and File I/O, while also utilizing @Dataclasses.

The Goal for this exercise:

```
- Create a @dataclass for a game character (name, level, inventory list).
- Write a function to save character data to JSON file.
- Write a function to load character data from JSON file.
- Test by creating, saving, and loading a character.
```
