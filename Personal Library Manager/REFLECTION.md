# Development

- What went well?:
  The logic of the functions went really well, I got the general concept and ideas right with my logic.txt file, and managed to translate that to python syntax relatively effectively.
- What was difficult?:
  Interacting with booleans, as I did not know that the most effective way of interacting with booleans is structuring the way you interact with them as if that interaction was a boolean, my mind kept wandering and trying to make IF statements as if they were strings when I am looking for booleans. I had to research and eventually asked AI tools how to structure my IF statements when searching for boolean data correctly.
- What did I learn?:
  Boolean interaction is the primary thing I have learned, I now know that when interacting with a boolean, the interaction must act like a boolean as well. I also learned that if you are using user input to make a new entry in a list of dicts, it is probably better to assign the new dict's attributes pre-creation so that you can expect those attributes. That way you dont have to convert the string into a True or False check.
- What would I improve?:
  I would like to implement a web-based interface and convert the project into an application, utilize a database instead of hardcoding the dictionaries into the development file, and expand the functions to include deletion, appending, and potential for file input and output.
